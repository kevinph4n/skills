---
name: idea-validate
description: Check if a concrete idea is worth building (demand, competitors, who already failed). Use when the user has a specific idea or problem statement. Not for brainstorming (use idea-hunt).
---

# Goal
Try to kill the idea with facts. Only survivors get built.

# Steps
1. Compress the idea into one sentence: who uses it, when, what it replaces. If impossible, clarify first.
2. Demand: evidence of searches, complaints or payment? What do people use today? "Nothing" may mean it doesn't hurt enough. Give 5 Mom Test questions (past behavior, never "would you use it?").
3. Competitors (must search): direct and indirect, including spreadsheets or doing nothing. Read their bad reviews.
4. Graveyard: who tried and died, why, does that reason still apply?
5. Gap: which difference do users actually care about?
6. Smallest test (1 week max, near-zero cost) with kill criteria set upfront.

# Rules
- Every market claim needs a source, otherwise label it "unverified".
- "No competitors" usually means you didn't look hard enough, or there is no market.

# Output
Verdict (green / yellow / red), competitor table, how it could die, test and kill criteria, sources.
If inside a project, save to `docs/idea.md`.
