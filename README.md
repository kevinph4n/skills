# skills

Personal agent skills for Claude Code. Not sure where to start: `/start-here`.

## Productivity

### Model-invoked
- [start-here](skills/productivity/start-here/SKILL.md): route to the right skill or flow
- [idea-hunt](skills/productivity/idea-hunt/SKILL.md): find a real, painful, niche problem worth solving
- [idea-validate](skills/productivity/idea-validate/SKILL.md): check demand, competitors and failed attempts for a concrete idea
- [idea-stress-test](skills/productivity/idea-stress-test/SKILL.md): find where a validated idea breaks (scale, money, distribution, risk)

## Engineering

### User-invoked
- [tech-stack-workflow](skills/engineering/tech-stack-workflow/SKILL.md): build a project phase by phase

### Model-invoked
- [tech-stack-rec](skills/engineering/tech-stack-rec/SKILL.md): recommend a proven core stack, niche tech only when justified
- [tech-validate](skills/engineering/tech-validate/SKILL.md): audit a stack before building, quiz the user after finishing

## Setup (Windows, Git Bash)
1. Clone this repo.
2. Set the user env var `CLAUDE_CONFIG_DIR` (e.g. `D:\Programming\.claude-config`) and reopen terminals.
3. `bash scripts/link-skills.sh`
